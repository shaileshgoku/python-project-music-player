# 🎧 Smart Music Player (Python)

A simple and interactive music player built using Python with CLI and GUI support.
This project allows users to play, pause, resume, and manage songs from a local playlist.

---

## 🚀 Features

* 🎵 Play music files
* ⏸ Pause and resume playback
* ⏹ Stop music
* 📂 Load songs from a folder
* 🔄 Change songs dynamically
* 🖥 GUI interface using Tkinter
* ⚡ Built using Pyglet for audio playback

---

## 🧠 Tech Stack

* Python
* Tkinter (GUI)
* Pyglet (Audio handling)
* OS module (File handling)

## ▶️ How to Run

1. Clone the repository

```
git clone https://github.com/shaileshgoku/python-project-music-player.git
```

2. Install dependencies

```
pip install pyglet
```

3. Run the app

```
python app.py
```
